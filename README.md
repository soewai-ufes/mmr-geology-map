# Myanmar Geology Map
Reference to Myanmar Geosciences Society (2014)

**Purpose:** To interpret ***Fault, Fold, Mineral Composite and Geo Region of Myanmar*** on interactive Web Map

## Data Source
- Township and Myanmar Townpoint [MIMU](https://geonode.themimu.info/layers/?limit=100&offset=0)
- Fault, Fold and Mineral Composite [Dagon BUMI](https://dagongeology.blogspot.com/2018/09/myanmar-geology-map-shape-file.html)
- Myanmar Geology Map [ORR & ASSOCIATES](https://www.orrbodies.com/resource/geology-burma-1500k/)
